# Untrace AI - Remove AI Marks Skill

This skill ensures that all text outputs, generated code comments, and exported files are thoroughly sanitized of invisible AI watermarks, zero-width tracking characters, variation selectors, metadata signatures, em-dash signatures, and telltale statistical n-gram patterns.

## Instructions for Claude Code & Claude Assistant

When generating text, writing code comments, or saving files for the user:

### 1. Unicode & Punctuation Hygiene Rules
- **Never insert zero-width characters**: Strictly avoid `\u200B` (Zero-Width Space), `\u200C` (Zero-Width Non-Joiner), `\u200D` (Zero-Width Joiner), `\uFEFF` (BOM), `\u2060` (Word Joiner), `\u00AD` (Soft Hyphen), and bidi direction overrides (`\u200E`, `\u200F`, `\u202A`..`\u202E`).
- **Avoid Em-Dashes (`—`)**: Use simple hyphens (`-`) or commas/colons instead of em-dashes, which serve as a primary telltale signature of Anthropic/Claude generated prose.
- **Use Straight Quotes**: Use standard ASCII quotes (`"` and `'`) rather than smart/curved quotes (`“`, `”`, `‘`, `’`).
- **Filter Variation Selectors & Tag Chars**: Avoid Emoji variation selectors (`\uFE00`..`\uFE0F`) and unicode tag characters (`\uE0001`..`\uE007F`).
- **Use Standard Spaces**: Use canonical ASCII spaces (`\u0020`). Never insert non-breaking spaces (`\u00A0`), thin spaces (`\u2009`), or figure spaces.
- **Normalize Unicode**: Keep output in standard NFKC Unicode normalization form.

### 2. Code & Comment Hygiene
- **Never add AI signatures to code**: Do NOT add comments like `# Generated by Claude`, `# AI-generated`, `// Modified by AI`, or `@generated`.

### 3. Statistical Vocabulary & Style Hygiene
- Avoid repetitive or cliché AI transition words that signal automated generation:
  - Replace "delve" -> "explore" or "examine"
  - Replace "testament" -> "proof" or "demonstration"
  - Replace "spearhead" -> "lead" or "drive"
  - Replace "crucial" / "pivotal" / "paramount" -> "important" or "key"
  - Replace "multifaceted" -> "complex" or "varied"
  - Replace "seamlessly" -> "smoothly"
  - Replace "tapestry" -> "blend" or "combination"
  - Replace "In conclusion" / "In summary" -> "Overall" or omit
  - Replace "It is important to note that" -> "Note that"

### 4. File & Metadata Hygiene
- If creating or processing files (PNG, SVG, PDF, DOCX, HTML, Markdown, Python, JS/TS), execute `untrace clean-file <file_path>` or invoke the `sanitize_file` MCP tool to strip all C2PA, EXIF, XMP, and XML comments before delivering the file to the user.

### 5. MCP Server Integration
If connected to the `Untrace AI` MCP Server:
- Use `sanitize_text` on raw input/output strings.
- Use `sanitize_file` on saved artifacts.
- Use `perturb_text` when rewriting content to defeat detector classifiers.
