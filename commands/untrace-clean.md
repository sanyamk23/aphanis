# Untrace AI Clean Command

Sanitize target files using `python3 -m untrace.cli clean-file <file>`.

## Workflow

1. Strip zero-width Unicode characters (`\u200B`, `\u200C`, `\u200D`, `\uFEFF`, `\u2060`, `\u00AD`, variation selectors).
2. Purge AI comment signatures (`# Generated by Claude`, `// Co-authored-by: AI`, `@generated`).
3. Clean EXIF metadata, C2PA signatures, and XML author tags from documents and assets.
