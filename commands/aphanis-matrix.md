# Aphanis Matrix Command

Calculates 4-Vector Stego Risk Matrix breakdown and entropy stats.

## Workflow

1. Calculate Shannon Entropy (bits per character).
2. Compute Type-Token Ratio (vocabulary diversity).
3. Evaluate Unicode, Statistical, Metadata, and Frequency vector risk scores.
