# Untrace AI Audit Command

Run `python3 -m untrace.cli check` or perform a 4-Vector Stego Risk Matrix audit on the target path.

## Workflow

1. Audit all 4 Stego Threat Vectors:
   - **Vector 1**: Invisible Unicode Watermarks (ZWSP `\u200B`, soft hyphens, BOM, variation selectors).
   - **Vector 2**: Statistical Model Risk & AI Cliché Telltales (*delve*, *testament*, *tapestry*, *pivotal*, etc.).
   - **Vector 3**: Code Comments & Container Metadata (`# Generated by Claude`, EXIF, C2PA signatures).
   - **Vector 4**: Spatial Frequency & Sub-pixel Noise.

2. Generate a zero-trust compliance summary report with Shannon entropy score and actionable recommendations.
