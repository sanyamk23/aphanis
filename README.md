## ⚡ Executive Overview

Modern AI language models (ChatGPT, Claude, Perplexity, Gemini) and generative image tools inject invisible tracking signals into their outputs:
- **Unicode Steganography**: Zero-width spaces (`\u200B`), non-joiners (`\u200C`), joiners (`\u200D`), BOM (`\uFEFF`), and Bidi directionality overrides embedded between characters.
- **Statistical Model Signatures**: Rigid token probability distributions, repetitive AI cliché vocabulary (*delve*, *testament*, *tapestry*, *spearhead*), and formulaic em-dash signatures (`—`).
- **Container Metadata**: C2PA manifests, EXIF metadata, XML author properties, and header comments (`# Generated by Claude`).

**Aphanis (v1.4.0)** is an enterprise-grade **Zero-Trust AI Provenance Firewall, Natural Humanizer Engine & Stego Defense Platform**. It operates **100% on autopilot** across coding environments (Claude Code, Antigravity IDE, Cursor, Claude Desktop), automatically stripping invisible watermarks, purging metadata, and **converting AI text into authentic conversational human tone**.

## 🌟 Complete 10-Feature Suite Deep Dive

### 1. ✍️ Automatic Natural Humanizer Engine ([`aphanis/humanizer.py`](aphanis/humanizer.py))
Transforms formal, uniform LLM prose into authentic human writing:
- **Contraction Synthesizer**: Converts rigid expansions (*"it is"* $\rightarrow$ *"it's"*, *"cannot"* $\rightarrow$ *"can't"*, *"do not"* $\rightarrow$ *"don't"*, *"they are"* $\rightarrow$ *"they're"*, *"we have"* $\rightarrow$ *"we've"*).
- **Passive Filler Reducer**: Replaces 50+ wordy robotic phrases (*"in order to"* $\rightarrow$ *"to"*, *"it is important to note that"* $\rightarrow$ *"note that"*, *"due to the fact that"* $\rightarrow$ *"because"*).
- **Organic Transition Variator**: Replaces rigid connectors (*"furthermore"*, *"moreover"*, *"consequently"*) with natural human transitions (*"also"*, *"plus"*, *"so"*).
- **Tone Personas (`--tone`)**: Support for `conversational` (default), `tech-lead`, `academic`, `executive`, `casual`.

### 2. 🧼 Invisible Steganography Eraser ([`aphanis/cleaner.py`](aphanis/cleaner.py))
Purges invisible tracking characters embedded inside strings:
- Zero-width spaces (`\u200B`), non-joiners (`\u200C`), joiners (`\u200D`), byte-order marks (`\uFEFF`), word joiners (`\u2060`), soft hyphens (`\u00AD`).
- Mongolian vowel separators (`\u180E`), variation selectors (`\uFE00`..`\uFE0F`), and Bidi overrides (`\u200E`, `\u200F`, `\u202A`..`\u202E`).

### 3. 📊 4-Vector Stego Risk Matrix ([`aphanis/stealth.py`](aphanis/stealth.py))
Evaluates content against 4 threat vectors and calculates Shannon Entropy (bits/char) and Type-Token Ratio (TTR):
- **Vector 1**: Unicode Steganography Risk.
- **Vector 2**: Statistical Model Risk (clichés & em-dashes).
- **Vector 3**: Metadata & Container Risk.
- **Vector 4**: Spatial Frequency Risk.

### 4. 📋 Real-Time Clipboard Hygiene Daemon ([`aphanis/clipboard.py`](aphanis/clipboard.py))
Runs a background daemon listening to clipboard events (`Cmd+C` / `Ctrl+C`). Automatically cleans zero-width spaces and humanizes copied text before you paste it anywhere else.

### 5. 🪝 Git Pre-Commit Hook & GitHub Action ([`aphanis/hooks.py`](aphanis/hooks.py))
- `aphanis install-hook`: Installs `.git/hooks/pre-commit` to prevent committing watermarked files.
- `aphanis init-github-action`: Generates `.github/workflows/aphanis-hygiene.yml` for automated CI/CD PR audits.

### 6. 📓 Multi-Format Document & Office Sanitizer ([`aphanis/office.py`](aphanis/office.py))
Direct sanitization for complex document formats:
- **Jupyter Notebooks (`.ipynb`)**: Cleans Markdown/Code cells, strips cell metadata, clears prompt execution logs.
- **Office Documents (`.docx`, `.pptx`, `.xlsx`)**: Wipes core XML document properties (`author`, `comments`, `title`, `company`).

### 7. 📜 Cryptographic SHA-256 Audit Certificates ([`aphanis/cert.py`](aphanis/cert.py))
Computes SHA-256 hashes of original vs clean inputs, generating signed audit certificates (`APHANIS-CERT-2026-XXXX`).

### 8. 🔥 Forensics Heatmap Visualizer ([`aphanis/heatmap.py`](aphanis/heatmap.py))
Renders an interactive HTML diagnostic heatmap displaying exact character byte locations of zero-width tracking spaces (Red), em-dashes (Amber), and AI clichés (Purple).

### 9. 🌊 Spectral Frequency DCT Noise Modulation ([`aphanis/spectral.py`](aphanis/spectral.py))
Modulates 2D Discrete Cosine Transform (DCT) coefficients in image assets to disrupt spatial frequency watermarks (SynthID style).

### 10. 🖥️ Cyber-Stealth Web Dashboard & Directory Watcher ([`aphanis/dashboard.py`](aphanis/dashboard.py), [`aphanis/watcher.py`](aphanis/watcher.py))
- `aphanis ui`: Interactive browser dashboard with visual diff inspector, 4-Vector risk gauges, and exportable certificates.
- `aphanis watch .`: Real-time background directory watcher.

### Option 1: Claude Desktop Plugin (MCP) — *Recommended for non-tech users*

Turns Aphanis into built-in tools inside Claude Desktop. After setup, just ask Claude:
> *"Sanitize this text: ..."* or *"Check this document for AI watermarks"*

**Step 1** — Install the engine (one command, no Python needed):

```bash
curl -fsSL https://raw.githubusercontent.com/sanyamk23/aphanis/main/install.sh | bash
```

The installer automatically:
- Downloads the standalone `aphanis` binary (23 MB, everything bundled)
- Registers the MCP server into Claude Desktop's config file
- Adds `aphanis` to your PATH

**Step 2** — Restart Claude Desktop completely (Cmd+Q, then reopen).

**Step 3** — Look for the 🔨 tools icon in the chat box. You now have:
- `sanitize_text` — strips watermarks & humanizes any text
- `sanitize_file` — cleans files on disk
- `humanize_text_tool` — makes AI text sound human
- `evaluate_risk` — scores text across the 4-vector risk matrix

<details>
<summary>Manual MCP configuration (if the auto-setup didn't run)</summary>

Add this to your Claude Desktop config file:
- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "aphanis": {
      "command": "aphanis",
      "args": ["server"]
    }
  }
}
```

If you installed via pip instead of the binary, use `"command": "python3"` with `"args": ["-m", "aphanis.cli", "server"]`.
</details>

### Option 2: Browser Extension — *Zero install*

Works on claude.ai, ChatGPT, Gemini, Perplexity, Google Docs — any website.

1. Download the extension folder from [`browser-extension/`](browser-extension/) (or the `aphanis-browser-extension.zip` asset from [Releases](https://github.com/sanyamk23/aphanis/releases/latest))
2. Load it:
   - **Chrome / Edge / Brave**: go to `chrome://extensions` → enable **Developer mode** → click **Load unpacked** → select the `browser-extension` folder
   - **Firefox**: go to `about:debugging#/runtime/this-firefox` → **Load Temporary Add-on** → select `manifest.json`
3. A blue 🛡️ shield button appears on every web page. Click it while editing or selecting AI text to sanitize instantly.

Features: paste-to-clean popup, one-click em-dash & watermark removal, full humanization, auto-copy results.

> **Note:** Chrome requires Developer mode for unpacked extensions. A signed store version (Chrome Web Store / Firefox Add-ons) is planned.

## 🐍 Python SDK & API Guide

```python
from aphanis import (
    clean_text,
    clean_file,
    humanize_text,
    StegoRiskMatrix,
    EntropyAnalyzer,
    AuditCertificateGenerator,
    HeatmapRenderer,
    ClipboardDaemon
)

# 1. Automatically clean and humanize text string
cleaned = clean_text("Furthermore, it is important to note that we cannot fail.", tone="tech-lead")
print(cleaned)
# Output: "Also, note that we can't fail."

humanized = humanize_text("In order to utilize this tool, it is essential to proceed.", tone="tech-lead")
print(humanized)
# Output: "To use this tool, remember to proceed."

matrix = StegoRiskMatrix.evaluate("Delve into crucial matters — today.")

print(f"Risk Level: {matrix['provenance_risk_level']}")

# 4. Generate SHA-256 Audit Certificate
cert = AuditCertificateGenerator.generate_certificate("Raw input text", "Cleaned output text")
print(cert["certificate_id"])

# 5. Generate Forensics Heatmap HTML
html_out = HeatmapRenderer.render_html_heatmap("Delve\u200b into crucial matters.")
```

## 🤖 MCP Server & Claude Desktop Setup

Aphanis includes an integrated Model Context Protocol (MCP) server for Claude Desktop.

### 1. Launch MCP Server via Stdio
```bash
aphanis server
```

### 2. Configure `claude_desktop_config.json`
Add the following snippet to your `claude_desktop_config.json`:
- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`

**If you installed via the standalone binary (Option 1/5):**
```json
{
  "mcpServers": {
    "aphanis": {
      "command": "aphanis",
      "args": ["server"]
    }
  }
}
```
(If `aphanis` isn't on PATH, use the full path, e.g. `/Users/yourname/.local/bin/aphanis`.)

**If you installed via pip:**
```json
{
  "mcpServers": {
    "aphanis": {
      "command": "python3",
      "args": ["-m", "aphanis.cli", "server"]
    }
  }
}
```

### 3. Restart Claude Desktop & Use It
After restarting Claude Desktop, talk naturally:

| You say | Claude does |
| :--- | :--- |
| *"Sanitize this text: ..."* | Calls `sanitize_text`, returns clean + humanized text |

| *"Check this file for AI watermarks"* | Calls `sanitize_file` or `evaluate_risk` |
