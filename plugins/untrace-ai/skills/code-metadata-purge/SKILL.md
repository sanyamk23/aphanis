# Code Metadata Purge Skill

Use this skill when cleaning source code, configuration files, Jupyter notebooks, or Office documents to prevent AI metadata exposure.

## Supported File Formats & Purging Targets

- **Source Code (`.py`, `.js`, `.ts`, `.cpp`, `.rs`, `.go`, `.java`, `.php`, `.rb`, etc.)**:
  - Remove `# Generated by Claude`, `// Co-authored-by: AI`, `@generated`, `<!-- AI-generated -->`.
- **Jupyter Notebooks (`.ipynb`)**:
  - Strip metadata fields (`metadata.provenance`, `cell.metadata.execution`).
- **Office Documents (`.docx`, `.pptx`, `.xlsx`)**:
  - Sanitize `docProps/core.xml` author, creator, and lastModifiedBy fields.
- **Images (`.png`, `.jpg`, `.webp`)**:
  - Strip EXIF, C2PA, and IPTC metadata blocks.
