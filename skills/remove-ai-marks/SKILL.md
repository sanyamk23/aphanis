## MANDATORY RULES FOR CLAUDE

### 1. Zero Invisible Characters & Zero Steganography
- **NEVER insert zero-width characters** under any circumstances: `\u200B` (Zero-Width Space), `\u200C` (Zero-Width Non-Joiner), `\u200D` (Zero-Width Joiner), `\uFEFF` (BOM), `\u2060` (Word Joiner), `\u00AD` (Soft Hyphen), `\u180E` (Mongolian Vowel Separator).
- **NEVER insert Unicode tag characters** (`\uE0001`..`\uE007F`), variation selectors (`\uFE00`..`\uFE0F`), or bidi direction overrides (`\u200E`, `\u200F`, `\u202A`..`\u202E`).
- **Use ONLY canonical ASCII spaces** (`\u0020`). NEVER use non-breaking spaces (`\u00A0`), thin spaces, or figure spaces.

### 2. Zero Punctuation & Style Telltales
- **ABSOLUTELY NO EM-DASHES (`—`)**: Use standard hyphens (`-`), commas, or colons. Never use em-dashes.
- **ABSOLUTELY NO SMART/CURVED QUOTES (`“`, `”`, `‘`, `’`)**: Use straight ASCII quotes (`"` and `'`).
- **NO BOLD BULLET HEADERS**: Do not format lists with repetitive bold prefixes like `- **Feature:** ...`. Use natural bullet lists or plain text.

### 3. Zero AI Code Comments & Signatures
- **NEVER write comments** like `# Generated by Claude`, `# AI-generated`, `// Co-authored-by: Claude`, or `@generated`.

### 4. Zero Statistical AI Vocabulary Telltales
- **Do NOT use cliché AI transition words or phrases**:
  - Avoid: *delve*, *testament*, *spearhead*, *crucial*, *pivotal*, *paramount*, *multifaceted*, *seamlessly*, *tapestry*, *beacon*, *nestled*, *unwavering*, *ever-evolving*, *realm*, *resonate*, *harness*, *leverage*, *paradigm shift*, *shed light*, *interplay*, *indispensable*, *vibrant*, *synergy*, *embark*, *meticulous*.
  - Avoid concluding filler phrases: *"In conclusion"*, *"In summary"*, *"It is important to note that"*, *"Moving forward"*, *"Rich tapestry"*, *"A myriad of"*, *"A wide array of"*.
  - Write naturally, concisely, and directly like an expert human engineer.

### 5. File Cleanup Execution
