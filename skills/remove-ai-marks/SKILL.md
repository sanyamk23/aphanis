## 🛡️ MANDATORY AUTOPILOT RULES FOR ALL OUTPUTS & FILE CREATIONS

### 1. Chat Responses, Documentation & Code Snippets
- **Zero Invisible Steganography**: NEVER insert `\u200B` (Zero-Width Space), `\u200C` (Non-Joiner), `\u200D` (Joiner), `\uFEFF` (BOM), `\u2060` (Word Joiner), `\u00AD` (Soft Hyphen), variation selectors (`\uFE00`..`\uFE0F`), or Bidi directionality overrides.

- **Zero Robotic Passive Fillers**: Replace passive filler phrases (*"in order to"* $\rightarrow$ *"to"*, *"it is important to note that"* $\rightarrow$ *"note that"*, *"due to the fact that"* $\rightarrow$ *"because"*, *"at this point in time"* $\rightarrow$ *"now"*).
- **Punctuation Hygiene**: NEVER write em-dashes (`—`). Use standard hyphens (`-`), commas, or colons. Use straight ASCII quotes (`"` and `'`) instead of curly smart quotes (`“` `”` `‘` `’`).
- **Zero AI Cliché Vocabulary**: Never use *delve*, *testament*, *spearhead*, *crucial*, *pivotal*, *paramount*, *multifaceted*, *seamlessly*, *tapestry*, *beacon*, *nestled*, *unwavering*, *realm*, *resonate*, *harness*, *leverage*.

### 2. Automatic File Writing (`WriteFile`, `EditFile`, `CreateFile`)
- **Zero AI Header Comments**: NEVER write comments like `# Generated by Claude`, `# AI-generated`, `// Co-authored-by: AI`, or `@generated` inside source files (`.py`, `.js`, `.ts`, `.html`, `.css`, `.json`, `.md`).
