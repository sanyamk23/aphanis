<!-- ✨ WHAT IS SKILL FINDER ✨ -->
<!-- ═══════════════════════════════════════════════════════════════════════════ -->

> [!IMPORTANT]
> **Skills are tools, not clutter.** Skill Finder follows a just-in-time workflow: **search, install, use, then auto-remove**. Your environment stays clean. Now with **3 amazing modes**: 🎭 Match, 🗺️ Map, 📊 Stats.

<table>
<tr>
<td width="33%" align="center">

### 🎭 Skill Match
Tinder-style matching with compatibility scores. Swipe right on the perfect skill!

</td>
<td width="33%" align="center">

### 🗺️ Skill Map
Visual knowledge graph showing how skills connect. Explore the constellation!

</td>
<td width="33%" align="center">

### 📊 Stats Dashboard
Points, levels, achievements. Level up your skill-finding prowess!

</td>
</tr>
</table>

## 🚀 Install

### Quick Install (Recommended)

```bash
npx skills add sanyamk23/skill-finder -g -y
```

> The `-g` flag installs globally — works in **all** your Claude Code sessions.

### Project-Only Install

```bash
npx skills add sanyamk23/skill-finder -y
```

> Installs only for the current project.

## 🎭 Skill Match — Deep Dive

### How Compatibility Works

```
compatibility = (install_factor × 40) + (relevance × 35) + (recency × 25)

┌──────────────────────────────────────────────────────────┐
│                                                          │
│  Install Factor (40%)                                    │
│  ████████████████████████████████████████ 40%            │
│  ← Based on install count (30K = max)                    │
│                                                          │
│  Relevance (35%)                                         │
│  ██████████████████████████████████ 35%                  │
│  ← Keyword match strength                                │
│                                                          │
│  Recency (25%)                                           │
│  █████████████████████████ 25%                           │
│  ← How recently updated                                  │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### Match Outcomes

| Your pick | What happens |
|---|---|
| Card number | Install that skill |
| "None" / "Skip" | Search again |
| "All" | Install top match |
| "Surprise me" | Random from top 3 |

## 🗺️ Skill Map — Deep Dive

### Reading the Map

```
                    ★ CENTER SKILL
                   / | \
                  /  |  \
        RELATED ←   →   ← RELATED
              |       |
              ↓       ↓
         SUB-RELATED  SUB-RELATED

Legend:
  ★ = The skill you searched for (center of universe)
  ● = Related skills (same category)
  ○ = Sub-related skills (adjacent categories)
  | = Connection / relationship
  ← → = Skills relate to each other
```

### Example: "testing" Constellation

```
🗺 SKILL CONSTELLATION: "testing"

            ↓        ↓        ↓
```

## ❓ FAQ

<details>
<summary><b>What if no skill is found?</b></summary>

Claude will tell you and offer to help with its base capabilities. No hard feelings.

</details>

<details>
<summary><b>What if I want to keep a skill?</b></summary>

Just say "keep it" and the auto-remove step is skipped. You're in control.

</details>

<details>
<summary><b>How is compatibility calculated?</b></summary>

Compatibility = (install_factor × 40%) + (relevance × 35%) + (recency × 25%). It's an estimate, not a guarantee.

</details>

<details>
<summary><b>Are stats persistent?</b></summary>

Currently stats are session-based for fun. Persistent stats may be added in a future version.

</details>

<details>
<summary><b>Does this work with other AI agents?</b></summary>

Yes! Any agent supporting the skills.sh ecosystem works. See the Supported Agents section above.

</details>

<details>
<summary><b>Is this safe?</b></summary>

Skills run with full agent permissions. The `find` command shows risk assessments (Gen / Socket / Snyk). Always review before using.

</details>
